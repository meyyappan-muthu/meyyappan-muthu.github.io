This portfolio highlights my work as a Staff Software Engineer, focusing on:

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/meyyappan-muthu/meyyappan-muthu.github.io.git

# Navigate to directory
cd meyyappan-muthu.github.io

# Start a local server (any method works)
python3 -m http.server 8000
# OR
npx serve
# OR open index.html directly in browser
```

Visit: `http://localhost:8000`
